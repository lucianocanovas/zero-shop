Entorno de Pruebas con Soporte Thymeleaf

Componente preparado con dialectos de Spring Security y Thymeleaf.

Simulación en navegador: Logueado (Con cuenta)

Adaptaciones de Thymeleaf añadidas

Spring Security Dialect

  • sec:authorize="isAuthenticated()": Muestra el avatar y el menú de cuenta.
  • sec:authorize="!isAuthenticated()": Muestra el botón de iniciar sesión.
  • sec:authentication="name": Nombre del usuario autenticado.
  • sec:authorize="hasAnyRole(...)": Acceso directo al Dashboard si es ADMIN o EMPLOYEE.

Rutas y Fragmentos

  • th:fragment="navbar": Listo para importarse con th:replace.
  • th:fragment="sidebar": Menú lateral modularizable.
  • th:href="@{/}": Rutas dinámicas con contexto de la aplicación.
  • Formulario POST para th:action="@{/logout}" (CSRF seguro).
